HOW TO REPLACE THESE ILLUSTRATIONS WITH YOUR OWN PHOTOS

Each picture on the website is a separate file in this folder.
To use a real photo instead:

1. Prepare your photo (JPG), cropped to the same shape:
   hero.svg               720 x 560  (homepage, beside the headline)
   service-listing.svg    600 x 360  (eBay listing service)
   service-inventory.svg  600 x 360  (inventory service)
   who-wreckers.svg       400 x 260
   who-dismantlers.svg    400 x 260
   who-salvage.svg        400 x 260
   who-sellers.svg        400 x 260
2. Keep it small: under 200 KB (use squoosh.app to compress).
3. Easiest way: name your photo the same as the file it replaces but ending
   in .jpg (for example hero.jpg), upload it to this folder, then send the
   file name to whoever edits the site so the page points to the .jpg.

Only use photos you took yourself or that you have the right to use.
Do not show client names, prices or customer details in photos.
