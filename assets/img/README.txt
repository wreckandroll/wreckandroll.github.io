HOW TO REPLACE THE WEBSITE PHOTOS

Each picture is stored twice: a .webp file (smaller, used by modern browsers)
and a .jpg file (fallback). Replace BOTH with the same file name.

  hero              homepage, beside the headline
  ebay-listing-service   eBay listing card and eBay service page
  inventory-management   inventory card and inventory service page
  wrecking-yard     Who we help: auto wreckers and salvage yards
  parts-workshop    Who we help: auto dismantlers
  order-packing     Who we help: used auto parts sellers

Tips:
- Use square photos, at least 1000 x 1000 pixels, so they stay sharp.
- Keep each file under 200 KB (squoosh.app can make the .jpg and .webp).
- Only use photos you own or have the right to use, and never show client
  names, prices or customer details.
